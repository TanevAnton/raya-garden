# OpenAI's crawlers are separate robots.txt tokens - a rule for one does not
# cover the others - so each is named explicitly. OAI-AdsBot validates the
# landing pages of ChatGPT ads. Every group carries an empty "Disallow:"
# (the universally understood "allow everything" form) alongside "Allow: /",
# because Allow is a spec extension and a group holding only an Allow line
# can be read as empty by a strict parser. ASCII only, deliberately: no
# typographic dashes or quotes that a picky parser might trip over.
