# База данни на QR системата — описание на таблиците и полетата

Версия на софтуера 1.0.0, структура на базата v15. СУБД:
SQLite 3, един файл (`orders.sqlite`) на сървъра на хостинга, извън публичната
папка на сайта. Създава се и се обновява от самата програма
(`public/api/qr/_lib/core.php`).

Времената са Unix време (секунди от 1.1.1970 г. UTC; на екрана — в часовата
зона на София). Сумите са в евроцентове (1250 = 12,50 €) и включват ДДС.
Нищо от продажбите, плащанията, бележките и журнала не се изтрива. Изтриват се
само личните данни на гостите (имена, имейли) след 3 дни.

Направено от `scripts/qr-db-doc.mjs` — не се редактира на ръка.

## Продажби

### `orders`

Поръчки. Поръчка, платена в телефона, е продажба с УНП (`usn`).

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` 🔑 | цяло число | Системен номер на записа |
| `code` | текст | Код на поръчката, показван на госта и персонала (напр. R-0001) — системен номер на продажбата |
| `token_hash` | текст | SHA-256 на тайния ключ, с който гостът вижда поръчката си |
| `idem_key` | текст | Ключ срещу двойно изпращане от телефона |
| `payload_hash` | текст | SHA-256 на съдържанието на поръчката (проверка при повторно изпращане) |
| `table_no` | цяло число | Номер на масата |
| `status` | текст | Състояние: pending_payment (чака плащане), expired (неплатена, изтекла), new, accepted, served, cancelled (анулирана) |
| `cancel_reason` | текст | Причина за анулиране |
| `total_cents` | цяло число | Обща сума при създаването |
| `lang` | текст | Език на госта (bg/en) |
| `ip_hash` | текст | Необратим отпечатък на мрежовия адрес, за ограничение на честотата; изтрива се след 5 минути |
| `created_at` | цяло число | Дата и час на откриване на продажбата |
| `updated_at` | цяло число | Последна промяна |
| `seq` | цяло число | Пореден номер на промяната (за екраните) |
| `pay_status` | текст | Плащане: pending, paid, failed, expired, refunded |
| `checkout_session` | текст | Номер на плащането в Stripe (сесия) |
| `checkout_url` | текст | Адрес на страницата за плащане в Stripe |
| `checkout_expires` | цяло число | Срок на страницата за плащане |
| `payment_intent` | текст | Номер на плащането в Stripe (pi_…) |
| `paid_at` | цяло число | Дата и час на плащането (приключване на продажбата) |
| `refund_id` | текст | Номер на връщането в Stripe |
| `till_at` | цяло число | Кога е отбелязана в „За касата“ |
| `till_void_at` | цяло число | Кога е отбелязано сторно в „За касата“ |
| `tab_id` | цяло число | Сметка (tabs.id), ако е част от сметка |
| `guest_name` | текст | Име, дадено от госта (изтрива се след 3 дни) |
| `payer_name` | текст | Име на платеца от Stripe (изтрива се след 3 дни) |
| `void_cents` | цяло число | Сума на анулираните редове |
| `refund_due_cents` | цяло число | Дължима за връщане сума |
| `refunded_cents` | цяло число | Върната сума |
| `refund_error` | цяло число | 1, ако връщането е неуспешно |
| `till_cents` | цяло число | Отбелязана в касата сума |
| `till_void_cents` | цяло число | Отбелязана в касата сторнирана сума |
| `kitchen_status` | текст | Състояние за кухнята |
| `bar_status` | текст | Състояние за бара |
| `evening` | текст | Работна вечер (дата) |
| `tip_cents` | цяло число | Бакшиш (изключен — винаги 0) |
| `usn` | текст | Уникален номер на продажбата (УНП), даден при създаването |
